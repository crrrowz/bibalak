# Today at a Glance (Sample Plugin)

**License:** MIT  
**API Version:** `0.2.0`  
**Capabilities:** `read:decks`, `ui:panel`, `ui:command`

## What it does

- Lists due card counts (`new`, `learning`, `review`) per deck in a sidebar panel.
- Highlights the next deck to study with one-click **Study** navigation.
- Registers the command **Today at a Glance: Study next due deck** in the Command Palette (`Ctrl+K` / `⌘K`).
