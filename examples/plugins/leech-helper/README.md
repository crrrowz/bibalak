# Leech Helper (Sample Plugin)

**License:** MIT  
**API Version:** `0.2.0`  
**Capabilities:** `read:notes`, `ui:command`, `ui:panel`

## What it does

- Searches notes tagged `leech` (`ctx.notes.search("tag:leech", { limit: 50 })`).
- Displays them in the **Leech Helper** sidebar panel with one-click **Open in Browse**.
- Adds **Leech Helper: List leech cards** to the Command Palette (`Ctrl+K` / `⌘K`).
