# Sustaining Bibalak

Bibalak is free to use, study, change and share under `AGPL-3.0-or-later`.
The project is led by Hassanein Hassan Alkahafji and kept alive by the people
who use it.

## How you can help today

- **Use it and report what breaks.** A clear bug report with steps is worth
  more than most patches.
- **Improve the Arabic and English text.** Wording, plurals and right-to-left
  layout fixes are always welcome.
- **Contribute code or docs.** Start with [`CONTRIBUTING.md`](CONTRIBUTING.md).
- **Tell other learners.** Star the repository and share it with your study
  group.

## Sponsorship

There is no sponsorship channel yet. When one opens, it will be announced in
the release notes and a **Sponsor** button will appear on the repository page.
